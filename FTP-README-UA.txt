ЗАВАНТАЖЕННЯ НА FTP

1. Відкрийте FTP або File Manager вашого хостингу.
2. Перейдіть у public_html, www, htdocs або іншу кореневу папку домену.
3. Завантажте index.html з цього архіву.
4. Якщо на сервері вже є index.html, замініть його новим файлом.
5. Очистьте кеш браузера/CDN.

Сайт автономний: стилі, скрипти, зображення та PDF Resume вже вбудовані в index.html.

Повна інструкція з редагування знаходиться у файлі README-EDITING-UA.md вихідного проєкту.
